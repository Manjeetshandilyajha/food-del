# 🍔 Food Delivery Web Application

A modern and responsive Food Delivery Web Application built using the MERN Stack. Users can browse food items, add them to the cart, place orders, and enjoy a seamless online food ordering experience.

## 🚀 Features

- 🍕 Browse Food Categories
- 🔍 Search Food Items
- 🛒 Add to Cart
- ➕ Increase / Decrease Quantity
- 💳 Secure Checkout
- 👤 User Authentication (Login & Register)
- 📦 Order Management
- 📱 Fully Responsive Design
- ⚡ Fast Performance

---

## 📦 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/food-delivery.git
```

Move to project folder

```bash
cd food-delivery
```

Install dependencies

```bash
npm install
```

If using separate frontend and backend:

```bash
cd client
npm install

cd ../server
npm install
```

---

## ⚙️ Environment Variables

Create a `.env` file in the server folder.

```env
PORT=5000

MONGO_URI=Your_MongoDB_URL

JWT_SECRET=Your_JWT_SECRET
```

---

## ▶️ Run Project

Backend

```bash
npm run server
```

Frontend

```bash
npm run dev
```
